# Semideaf Woot-Off Checker archive

This directory contains the surviving Woot-Off Checker files and a static museum page added in 2026.

- `index.html`, `museum.css`, and `museum.js` are the modern static exhibit.
- The original PHP, HTML, Flash, ActionScript, cached data, and media files are preserved as artifacts.
- The exhibit does not contact Woot, execute the old tracker, load advertising, or load third-party analytics.
- The three original Semideaf MP3 alerts play through native browser audio controls.

The durable public link for the exhibit is `/woot/`, not `/woot/woot.php`.
